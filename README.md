## ⚡ О проекте

**Novar** — это приватный мессенджер, созданный для тех, кому важна полная конфиденциальность переписок, свободный обмен данными и независимость от внешних блокировок и цензуры.

> **Создано разработчиком:** `lynx`

---

## 🔒 Ключевые особенности

* 🛡️ **Сквозное шифрование (AES-GCM):** Полная защита сообщений прямо на устройстве. Ключи хранятся исключительно у участников диалога.
* 📞 **P2P-звонки:** Прямое соединение между клиентами с минимальной задержкой и без промежуточных серверов.
* 📁 **Отправка файлов до 1 ГБ:** Передача любых форматов (архивы, медиа, исходники) без ухудшения качества и сжатия.
* 🌐 **Работа без VPN и прокси:** Мессенджер стабильно функционирует в любых сетях без применения костылей для обхода ограничений.
* 🎨 **Material You Design:** Тёмная интерфейсная тема в эстетичных синих тонах с поддержкой адаптивных компонентов Material Design 3.
